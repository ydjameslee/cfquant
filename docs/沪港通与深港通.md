# 沪港通与深港通

已接入 QMT 港股通账户的单笔/批量委托、同步/异步接口、撤单、资金/持仓/委托/成交查询及回报。普通桥、极速桥及 ctypes 共用本分支的委托身份校验；独立 Lite 保留自身实现，尚未包含完整的交易日和请求标记匹配修复。验证使用本地模拟 QMT，不代表券商实盘已经验收。

## 账户与代码

| 通道 | 账户类型 | 账户类型数值 | 证券代码示例 |
| --- | --- | --- | --- |
| 沪港通 | `HUGANGTONG` | `7` | `00700.HGT` |
| 深港通 | `SHENGANGTONG` | `11` | `00700.SGT` |

在 Web 初始化或绑定页面选择对应账户类型。同一资金账号可分别绑定两类账户，账户标识包含账户类型，查询和回报订阅分别处理。自动导入策略时，也按账户类型匹配 QMT 的原生账号 Key。

港股通不使用“SH/SZ 独立市场路由”；请分别绑定沪港通、深港通账户及其 QMT。本分支兼容五位数字、`HK.00700`、`00700.HK`，也接受显式 `.HGT` 或 `.SGT`。必须选择明确的港股通账户类型，由桥接层转换为相应原生通道；不能用 `.SH/.SZ` 表示港股通通道。账号与后缀不匹配会在提交前报错。

`.HK` 是香港市场行情及本分支统一回报代码；交易通道由账户类型决定，不能仅凭 `.HK` 选择通道。Web 支持 `.HK/.HGT/.SGT` 行情代码输入；实际行情、历史数据、交易日历和标的资料由 QMT 数据源及权限决定。`HSGTFlag` 保留原生结果，基础资料回退仍标记为部分资料，不根据后缀伪造标的资格。

## Python 用法

```python
from cfquant import xtconstant
from cfquant.xttype import StockAccount
from cfquant.xttrader import XtQuantTrader

# 使用 Web 中保存的账户绑定；也可显式指定 bridge_id。
account = StockAccount("你的资金账号", "HUGANGTONG")
trader = XtQuantTrader(account=account)
trader.start()
try:
    if trader.connect() != 0:
        raise RuntimeError(trader.last_connect_error)
    trader.subscribe(account)
    print(trader.query_stock_asset(account))
    print(trader.query_stock_positions(account))
    print(trader.get_hkt_exchange_rate(account))
finally:
    trader.stop()
```

委托使用已有的 `order_stock` / `order_stock_async`，`STOCK_BUY=23`、`STOCK_SELL=24`。例如沪港通委托的证券参数为 `00700.HGT`，深港通为 `00700.SGT`。批量接口使用 `CfQuantTrader`，每批仅对应一个账户类型；批量撤单可指定 `market="HGT"` / `"SGT"` 或完整证券代码。异步返回的 `seq` 不是可撤单的委托编号。共用桥通过内部编号撤单时，还需传入 QMT 返回的 `trading_day`；账户类型、账号、交易日与原始 `m_nRef` 必须唯一匹配。详见[委托身份与交易日](委托身份与交易日.md)。

沪港通/深港通 `order_stock` 当前适配普通买卖操作（23/24）。本分支共用桥当前仅支持 `FIX_PRICE=11`、按股数下单及整手数量，使用 QMT 合约信息的 `VolumeMultiple` 校验；缺少每手股数时拒绝下单。不要把回报字段 `enum_EBrokerPriceType` 的 92/93/94 直接当成 `prType`。本项目不硬编码每手股数、价格档位、交易时段、汇率或资格名单，由券商 QMT 校验和返回。

`get_hkt_exchange_rate(account)` 返回 QMT 原生汇率字典；终端缺少该函数时明确抛出 `NotImplementedError`，不会构造汇率。该接口是 cfquant 对大 QMT 的扩展。

更新后需要重新部署相应桥接核心并重启 QMT 策略，旧的 Lite 文件不会自动获得新逻辑。还需使用已开通相应权限的券商账号完成实机行情、查询、委托与撤单验收。
