# QMT 交易日自动重启与登录

新绑定默认开启“自动启动并按交易日重启 QMT”，在每个 A 股交易日北京时间 **09:00** 重启，周末和法定休市日不执行计划重启。项目负责启动绑定目录的终端，并通过 Qt 组件完成登录。

开启此功能时，QMT 目录、登录账号和登录密码均为必填。绑定、首次初始化和新手引导都会在关闭 QMT 前校验，后端也会独立校验；缺少信息不能保存。即使客户端记住了密码，项目登录时也统一使用绑定中保存的账号和密码。编辑已有绑定时，登录账号和目录不变可留空复用已保存的加密密码；更换账号或目录后需重新填写对应密码。关闭此功能后不要求登录信息。

## 使用方式

在绑定设置中填写 QMT 安装目录、QMT 登录账号和登录密码，勾选“自动启动 QMT”，确认交易日重启时间后保存。登录账号是客户端登录界面使用的账号，可能不同于绑定资金账号。已有绑定的自定义时间和明确保存的空时间列表继续保留；原来没有计划重启的绑定可以添加 `09:00`。删除全部时间可关闭计划重启。

项目需要保持运行。服务器使用的时区不影响计划时刻，调度统一采用北京时间。程序重启后可补执行最近 10 分钟内错过的计划，避免正常轮询延迟造成漏跑；不会在中午启动项目时补执行早晨的重启。

新功能需要重启项目后加载。运行环境的 Windows 依赖已加入 `requirements.txt` 和包依赖：Frida 17.x、pywin32；Qt 组件代理也已纳入发行包。

## 每次重启

1. 验证组件自动登录所需依赖、客户端版本和已保存密码的解密能力。
2. 按可执行文件的完整路径精确查找该终端，强制结束旧进程及其子进程，轮询确认退出后才启动新进程。无法查询进程或旧进程未退出时，停止本次启动并显示原因。
3. 等待新进程的登录组件就绪，清空原有账号和密码，重新填入绑定中配置的账号；即使账号相同也重新填写。
4. 填入绑定中保存的密码后提交一次，不尝试客户端记住的密码，也不在密码被拒绝后连续重试。
5. 确认对应登录用户的主界面出现后记录“已登录”，之后由现有的 QMT 自启动策略继续建立项目连接。

登录组件调用在 QMT 自己的界面线程上执行，不依赖模拟鼠标、键盘、坐标或剪贴板。客户端自己可能在登录完成时激活窗口。

计划重启、手动重启都会结束旧进程，即使旧登录任务尚未结束。项目启动时若发现残留 QMT，也先结束后重新打开。重复的普通启动请求会等待同一个正在进行的登录任务；旧任务的迟到结果不会覆盖新任务的状态。新进程仍提示验证码时停止本次尝试并显示原因。

同一安装目录在同一交易日、同一计划时刻只执行一次，即使有多个绑定或 Web 服务中途重启。登录失败会显示失败原因，不会取消未来交易日的计划。网络超时、验证码和未知错误不会触发连续密码尝试。

## 密码与状态

密码使用 Windows DPAPI 按当前 Windows 用户加密，保存在运行配置目录的 `qmt_login_credentials.json`，与普通账号配置分开。普通配置接口只返回登录账号及“已保存密码”标志，不返回明文或密文。密码输入框留空保留原密码；输入新密码则替换。

输入密码时可点击“显示密码／隐藏密码”。编辑已有绑定时，点击“查看已保存密码”才通过专用接口读取该绑定的密码；接口沿用账号配置的访问认证，并禁止缓存。仅查看不会重新提交或覆盖密码，明文不进入页面全局状态、浏览器持久存储或日志；隐藏已保存密码、修改账号／目录、关闭窗口时清空显示。迟到的读取响应不会填入关闭后重新打开的表单。

换机器或换 Windows 运行用户后，需要重新保存密码。此限制来自 [Windows DPAPI 的用户与机器绑定](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

绑定列表和启动提示显示启动、登录中、已登录及失败状态。“已登录”表示 QMT 客户端认证完成；策略桥接是否在线仍由原有连接状态显示。

## 验证与适用范围

- 已实测国金模拟 `2.1.19.200` 和华泰模拟 `2.1.19.1` 的组件登录，它们使用 Qt 5.6.2 x64。
- 华泰已验证最小化窗口下的已有密码直接登录、空密码补填登录。
- 集成后的华泰模拟端已实测完整重启链路：旧进程 84560 退出，新进程 76836 启动并登录成功，其余三个 QMT 进程未改变。
- 自动化测试覆盖节后首个交易日、周末调休仍不交易、前次失败不阻断下一交易日、同目录去重、项目重启后的去重、旧进程退出失败、密码不泄露到配置或接口，以及桌面和手机宽度的表单行为。

交易日历使用项目现有的 `pandas-market-calendars` SSE 日历。超过已公布休市数据的年份会明确报错，避免把节假日当作交易日；需要随节假日公告更新依赖。2026 年国庆后首个交易日为 10 月 8 日，10 月 10 日周六仍休市，参见 [上交所公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260915_10832273.shtml)。

当前组件适配限定 Qt 5.6.2 x64。其他券商内部组件变化、验证码、锁屏、远程桌面断开或开机无人登录 Windows 的环境仍需要相应验证。此功能不会自动解决 Windows 会话启动问题。

实现入口：`cfquant_web_server.py` 的自动启动、重启调度与登录任务；`cfquant/qmt_component_login.py`、`cfquant/qmt_component_agent.js` 的组件操作；`cfquant/qmt_credentials.py` 的密码保存。
