# 沪港通、深港通（大 QMT / ctypes）

账户配置支持 `STOCK`、`HUGANGTONG`（7）、`SHENGANGTONG`（11）。同一资金账号的三种账户使用独立桥接及托管策略，不要将桥接 ID 互换。已有普通账户沿用原托管目录，避免升级后原模型引用的控制文件失效。

网页刷新后，在账户配置和交易面板中选择对应港股通账户。支持资产、持仓、委托、成交查询及普通限价买卖、撤单。SDK 使用 `StockAccount(account_id, "HUGANGTONG", bridge_id=配置中的桥接ID)` 或 `SHENGANGTONG`，调用原有查询、下单、撤单方法。

输入港股代码例如 `00700.HK`，保留五位数字。也可使用 `HK.00700` 或裸五位代码；显式 `.HGT`/`.SGT` 必须与所选账户类型一致。桥接将交易代码转换为对应的 `.HGT` 或 `.SGT`，回报统一显示 `.HK`，并保留账户类型区分通道。

首版交易限制：

- 仅限价买入或卖出，`price_type=11`，`qmt_order_type=1101`。
- 价格单位为港币，数量单位为股；数量必须符合 QMT 合约信息中的每手股数。
- 不支持碎股特殊委托、竞价特殊委托和算法单。
- 无法读取每手股数、账户类型绑定失败或代码与账户不匹配时，明确报错，不回退到普通账户或另一港股通账户。
- 查询保留 QMT 原始币种、参考汇率及人民币金额字段，不直接用人民币可用资金除以港币报价计算可买股数。

自动测试使用替身交易函数，不会发送实际委托。通过查询和参数测试不等于真实委托已由券商受理；实盘下单验收应由用户明确指定。

本次扩展只修改 cfquant，未修改 FutuTrader。

更新本地定制版本时，通过 Git 合并上游并保留这些改动。作者网站更新包不包含本地定制代码，直接覆盖更新可能丢失港股通支持。
